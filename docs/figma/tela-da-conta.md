# Área Logada (Conta)

Esta seção apresenta os desenhos e especificações da interface da **Área Logada** (Conta) do usuário.

## Visão Geral

A interface centraliza as principais interações do usuário após a autenticação, contendo o menu lateral para navegação entre as seções (como "Meus pedidos" e "Meu perfil") e a área de exibição de conteúdo.

### Mobile

## Componentes

- **Header Logado:** Apresenta o menu do usuário com acesso rápido ao perfil e pedidos.
- **Navegação Lateral:** Utilizada para alternar rapidamente entre "Meus pedidos" e "Meu perfil" (destacando o item ativo).
- **Área de Conteúdo:** Onde são exibidas as listas de pedidos, formulários de edição de perfil, etc.
