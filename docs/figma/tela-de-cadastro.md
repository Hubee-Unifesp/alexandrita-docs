# Tela de Cadastro

A página de registo ("Criar conta") divide-se em duas secções principais: uma área de comunicação à esquerda com a mensagem "Tudo começa com uma conta simples." e o formulário de preenchimento à direita[cite: 14]. Todo o design foi concebido para suportar na perfeição os modos claro e escuro[cite: 14].

## Formulário e Campos
O formulário recolhe as informações essenciais para a criação de uma nova conta[cite: 14]:
* **Seleção de Perfil:** O utilizador deve escolher o seu objetivo na plataforma selecionando um dos cartões: "Quero comprar ingressos" ou "Quero organizar eventos"[cite: 14].
* **Dados Pessoais:** Campos de texto normalizados para "Nome completo" e "E-mail"[cite: 14].
* **Segurança:** Campos para "Senha" e "Confirmação de senha", que incluem um ícone lateral (olho) para revelar ou ocultar a palavra-passe[cite: 14].
* **Ações:** O formulário termina com o botão principal de submissão ("Criar conta") e inclui um atalho no rodapé para utilizadores já registados ("Já tem conta?")[cite: 14].

## Estados de Autenticação e Validação
O design do Figma documenta de forma exaustiva os diferentes estados de interação dos componentes do formulário[cite: 14]:

* **Cartão de perfil:** Pode apresentar-se nos estados "Não selecionado", "Selecionado" (com contorno e fundo destacados) e "Erro" (exigindo a escolha com a mensagem "Escolha um perfil")[cite: 14].
* **Campos de texto:** Prevêem os estados "Com foco", "Preenchido" e "Erro" (exibindo texto de ajuda a vermelho, como por exemplo "As senhas não coincidem")[cite: 14].
* **Botão primário:** O botão de ação altera visualmente entre "Habilitado", "Desabilitado" (cinzento) e "Carregando" (com um ícone de *spinner* a girar)[cite: 14].
* **Alerta geral:** Foi desenhado um banner de erro de sistema que surge no ecrã com a mensagem "Não foi possível criar sua conta. Tente novamente."[cite: 14].

## Ecrãs Alternativos ("Em breve")
O ficheiro documenta também um ecrã de "Em breve"[cite: 14]. Este ecrã é utilizado para bloquear temporariamente funcionalidades não lançadas, exibindo o botão "Explorar os eventos" e um grafismo de uma janela com o título "PRÓXIMA ATRAÇÃO"[cite: 14].
