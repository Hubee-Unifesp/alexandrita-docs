# Header / Navbar

O cabeçalho (Header) da plataforma Hubee possui diversas variações de layout e adapta-se perfeitamente aos modos claro e escuro[cite: 12].

## Estrutura e Navegação
Os designs exploram diferentes disposições para o menu[cite: 12]:
* **Layouts:** O logótipo pode estar posicionado à esquerda ou ao centro, e existe também uma versão em formato de "pílula" flutuante[cite: 12].
* **Links Principais:** A navegação padrão inclui "Início", "Eventos" e "Meus Ingressos"[cite: 12]. O link "Meus Eventos" pode aparecer diretamente no menu ou ser movido para as opções do utilizador[cite: 12].
* **Ícones e Ações:** À direita, o menu exibe ícones para o carrinho de compras, notificações (sino) e perfil de utilizador[cite: 12]. Para utilizadores não autenticados, é exibido um botão "Entrar"[cite: 12].

## Temas e Cores
O design inclui um botão para alternar entre o modo visível (ícones de sol e lua), que pode ser afixado no topo ou colocado dentro das opções do utilizador[cite: 12]. As anotações de design indicam o uso de *tokens* específicos, como `hubee/50` para texto, `hubee/400` para *hover* e `hubee/800` para a caixa principal[cite: 12].
