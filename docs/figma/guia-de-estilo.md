# Guia de Estilo

Aqui apresentamos a base visual do Hubee, incluindo a paleta de cores, tipografia e elementos gráficos, tanto para o tema claro como para o escuro.

## Cores e Tipografia
O sistema utiliza tons de amarelo/dourado ("hubee"), tons neutros para fundos e textos, e cores de feedback (sucesso, aviso e destrutivo). A tipografia principal baseia-se nas fontes Maragsa e Inter, com variações de peso (400 e 800).

## Elementos Gráficos
Os componentes interativos, como botões switch, caixas de texto, menus dropdown e botões de ação (como "Save changes" e "Continue"), foram desenhados para se adaptarem perfeitamente aos dois temas.
