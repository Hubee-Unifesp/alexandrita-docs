# Introdução às Regras de Negócio

Esta seção reúne as regras de negócio do projeto Alexandrita: fluxos,
políticas, cálculos e decisões de produto que não são óbvias a partir do
código.

## O que documentar aqui

- Regras e políticas de negócio (ex: regras de cobrança, elegibilidade, limites).
- Fluxos de usuário e casos de uso importantes.
- Glossário de termos específicos do domínio.
- Decisões de produto e o motivo por trás delas.

## Exemplo de estrutura sugerida

```
docs/regras-negocio/
  intro.md
  glossario.md
  fluxos/
    cadastro-de-usuario.md
  politicas/
    politica-de-cancelamento.md
```

> Substitua este conteúdo pelas regras de negócio reais do projeto.
