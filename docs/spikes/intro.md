# Introdução aos Spikes

Esta seção reúne resultados de spikes técnicos e sessões de estudo do time:
investigações pontuais sobre uma tecnologia, biblioteca ou abordagem antes de
adotá-la no projeto.

## O que documentar aqui

- Pergunta/objetivo do spike (o que precisava ser respondido).
- Tempo investido e prazo (spikes são timeboxed).
- O que foi testado/comparado e as conclusões.
- Decisão tomada a partir do resultado (ou link para o ADR correspondente).
- Sessões de estudo em grupo: tema, principais aprendizados e referências.

## Exemplo de estrutura sugerida

```
docs/spikes/
  intro.md
  2026-02-avaliacao-de-fila-de-mensageria.md
  sessoes-de-estudo/
    2026-01-drizzle-orm.md
```

> Substitua este conteúdo pelos spikes e sessões de estudo reais do time.
